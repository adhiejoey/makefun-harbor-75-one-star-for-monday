A one-star restaurant review of Monday: a diner who booked a table for the weekend gets seated at 6 a.m., served cold alarms, and billed for five days — a short, quotable complaint that could only be about Monday.

## How it works

`main.ts` writes the single-line review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), using only the Node standard library and no network.
